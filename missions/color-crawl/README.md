# Colour Crawl

A four-step beginner mission introducing the **color sensor**. Drive east
over four colored stripes — red, yellow, green, blue — and the sensor on
port C reads each as you pass over it.

## Steps

1. **Detect the red line**    (10 pts) — `color.C == 'red'`
2. **Detect the yellow line** (10 pts) — `color.C == 'yellow'`
3. **Detect the green line**  (10 pts) — `color.C == 'green'`
4. **Detect the blue line**   (10 pts) — `color.C == 'blue'`

Total: **40 points**. Steps complete in order (each requires the previous).

## Field

Default mat, robot at (350, 163), facing north. Four vertical colored
stripes at x = 800, 1200, 1600, 2000 mm.
